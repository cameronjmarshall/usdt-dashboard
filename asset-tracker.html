Holdings

Moving weighted-average cost in GBP
Cost basis uses historical trade FX. Market value uses the latest price and current FX you have supplied. Sale proceeds are excluded from holdings; this version does not track a cash account.

Trade ledger

Trades are calculated by date, then their entry order
Import columns: date, ticker, name, type, quantity, price, currency, fees, fx, assetClass, note. FX means GBP per 1 unit of the trade currency. Fees use that same currency. CSV imports append trades; identical existing trades are skipped. Shorts are not supported.

Prices

Set prices manually, import CSV, or connect Alpha Vantage
Enter prices in each asset’s trade currency. Use GBX for UK shares quoted in pence. For automatic updates, supply the provider symbol and confirm the provider uses that same quote currency. Prices and FX retain their timestamps; they are never presented as real-time.

Current exchange rates

GBP per 1 unit of foreign currency · manually maintained
GBP = 1.00 · GBX = 0.01. Current FX never changes the historical rates recorded against your trades.

Move the app to another PC

This entire app is one HTML file. No ZIP, Python, installation or external libraries are required.

  1. Move the HTML file itself, or copy the app code.
  2. On Windows, paste into Notepad. Choose Save as → All files, use UTF-8, and name it asset-tracker.html.
  3. Double-click the file to open it in Edge or Chrome.
  4. Export a portfolio backup here, then import it on the other PC to move your trades and prices.
The HTML file contains the application code only. Trades are stored separately in the browser. Moving, renaming or updating the HTML file may change access to that browser storage; export a backup first.

Calculation notes

  • Buys add quantity and cost, including fees. Sells release the corresponding share of the weighted-average cost.
  • Realised gains deduct sale fees; unrealised gains include the effect of current FX.
  • GBP is the reporting currency. FX is GBP per one unit of the quoted currency.
  • No dividend, cash, split, bond accrued interest or tax-rule engine is included. Prices are per asset unit; bond prices per £100 nominal need conversion first.
  • Gain percentages are position gains against cost, not time-weighted portfolio returns. All figures exclude income.
